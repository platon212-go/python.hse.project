# Python HSE Project — Анализ CSV

1. Скачайте датасет по ссылке: <https://www.kaggle.com/datasets/sanarpit/raw-data>.
2. Поместите CSV-файл в `data/raw-data.csv`.
3. Откройте `project_analysis.ipynb` в Jupyter/Colab и запустите ячейки сверху вниз.

В ноутбуке уже реализованы все требуемые пункты: описание признаков, фильтрация/сортировка, новые признаки, частотные и сводные таблицы, обработка пропусков и выбросов, визуализации и интерпретации.
